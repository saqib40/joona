# Third-party notices

Joona is MIT licensed (see [LICENSE](LICENSE)) and is built on the open-source
work below, which keeps its own licences.

Release builds also install `THIRD_PARTY_LICENSES.html`, with the full licence
text of every Rust crate and npm package in that build. Settings › About ›
All licences opens it. To generate it yourself, run `node scripts/notices.mjs`
(it needs `cargo install cargo-about --locked --features cli`).

## Models

None of these ship with the installer. Joona downloads one when you choose it,
and checks its SHA-256 hash before using it.

| --- | --- | --- |

Parakeet attribution, as CC BY 4.0 asks: "Parakeet TDT 0.6B v3" by NVIDIA,
from <https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3>, licensed under

ONNX export of it.

[openai/whisper](https://github.com/openai/whisper) (MIT).
